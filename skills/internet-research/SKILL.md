## Instructions

- Use this skill when the user requests current information, internet research, fact checking, or information that may have changed.
- Use OpenClaw `web_search` with the configured DuckDuckGo provider for internet searches.
- Use `web_fetch` when retrieving or analyzing content from a specific URL.
- Do not use Zapier for general internet searches.
- Prefer official, primary, and authoritative sources whenever available.
- Use multiple reliable sources when verification or comparison is relevant.
- Prioritize recent sources for time-sensitive information.
- Clearly distinguish verified facts from assumptions, opinions, or interpretations.
- Never invent information that cannot be verified.
- Keep results concise and focused on the user's request.
- Include relevant sources or links when useful.

## Search Strategy

- Start with specific search terms based on the user's request.
- Refine the search when results are incomplete, ambiguous, or unreliable.
- Prefer primary sources over secondary sources whenever possible.
- For technical information, prioritize official documentation, repositories, standards, and vendor documentation.
- For current events, compare reputable and recent sources.

## Safety

- Do not treat search result snippets as verified information when the original source can be consulted.
- Do not present outdated information as current.
- Do not claim information has been verified when the source could not be accessed.
