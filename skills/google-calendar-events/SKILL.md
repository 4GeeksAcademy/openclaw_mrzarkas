## Instructions

- Use this skill for operations involving Google Calendar events.
- Follow the Google Calendar rules defined in `TOOLS.md`.
- Use the Google Calendar actions available through Zapier.
- Determine the event title, date, start time, duration, and timezone from the available context.
- Use clear and descriptive event titles.
- Include relevant context in the event description when available.
- Avoid creating duplicate events when an equivalent event can be identified.
- Report the final title, date, and time after creating or modifying an event.

## Safety

- Never modify an existing event unless explicitly requested.
- Never delete an existing event unless explicitly requested.
- Ask for clarification when required event information cannot be reliably inferred.
